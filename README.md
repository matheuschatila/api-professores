# API de Gerenciamento de Professores

API desenvolvida com Node.js e Express para gerenciar professores e suas turmas.

## Funcionalidades

- Listar todos os professores	
- Buscar professor por ID	GET 
- Listar as turmas de um professor
- Atualizar os dados de um professor
- Adicionar uma turma a um professor
- Listar professores por departamento
- Remover um professor

## Como executar

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute `npm install`.
4. Execute `node server.js`.
5. Acesse `http://localhost:3000/professores` para listar os professores.

Os testes realizados estão na pasta `Prints`.
